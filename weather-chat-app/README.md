# 天気チャットアプリ (Weather Chat App)

## 概要

このアプリケーションは、Next.js, AI SDK (Google Generative AI), Playwright, そして Google Gemini API を活用して開発された、天気情報を教えてくれるインタラクティブなチャットボットです。ユーザーが入力したメッセージに基づいて、指定された場所の天気情報（現在はダミー）を会話形式で提供します。

## 主な機能

*   ユーザーと自然な会話形式で対話します。
*   指定された場所の天気情報を提供します。
    *   **注意**: 現時点では、天気情報は固定のダミーデータを返します。実際の天気予報は表示されません。

## 使用技術

*   **フレームワーク**: Next.js (React, TypeScript)
*   **AI**: Google Gemini API
*   **AI SDK**: Vercel AI SDK の概念に沿った `@google/generative-ai` ライブラリを直接使用
*   **ブラウザ自動操作**: Playwright (将来的な天気情報取得のため)
*   **パッケージ管理**: npm

## セットアップと実行方法

1.  **リポジトリのクローンまたはダウンロード**:
    ```bash
    # HTTPSの場合
    git clone <リポジトリURL>
    # または、ZIPファイルをダウンロードして展開
    ```

2.  **プロジェクトディレクトリへの移動**:
    ```bash
    cd weather-chat-app
    ```

3.  **必要なパッケージのインストール**:
    ```bash
    npm install
    ```

4.  **環境変数の設定**:
    プロジェクトのルートディレクトリ (`weather-chat-app` 直下) に `.env.local` という名前のファイルを作成し、以下のようにご自身の Google Gemini API キーを設定してください。
    ```env
    GOOGLE_GEMINI_API_KEY=YOUR_API_KEY
    ```
    `YOUR_API_KEY` の部分を、実際のAPIキーに置き換えてください。

5.  **開発サーバーの起動**:
    ```bash
    npm run dev
    ```

6.  **アプリケーションへのアクセス**:
    ウェブブラウザを開き、 `http://localhost:3000` にアクセスしてください。

## 今後の展望 (任意)

*   **実際の天気情報取得**: Playwright を使用して、実際の天気予報サイトからリアルタイムの天気情報をスクレイピングする機能の実装。
*   **高度な地名抽出**: より高度な自然言語理解 (NLU) 技術を導入し、ユーザーのメッセージからより正確に地名を抽出する機能の強化。
*   **チャット履歴の永続化**: ユーザーの会話履歴をデータベースなどに保存し、セッションを跨いでも会話を継続できるようにする機能。
*   **UI/UXの改善**: より洗練されたチャットインターフェースの提供。

## 注意点

*   このアプリケーションを動作させるためには、**Google Gemini API キーが必須**です。`.env.local` ファイルに正しく設定してください。
*   **現在のバージョンでは、天気情報はダミーデータを返します。実際の天気予報は表示されませんので、ご注意ください。**
*   Playwright のブラウザドライバは `npm install` 時に自動的にダウンロード・インストールされるはずですが、環境によっては手動でのセットアップ (`npx playwright install`) が必要になる場合があります。
